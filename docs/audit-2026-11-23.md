# Audit technique du 23 novembre 2026

Base examinée : main 762d4a0 ; hébergement Gandi conservé.

## Corrections

- Cache public explicite de 60 secondes. Contrôle après transfert des URL réelles (sans paramètre anti-cache), avec comparaison SHA-256 des 13 fichiers publics et des deux URL d’accueil. Délai maximal de convergence 240 secondes pour absorber les anciennes entrées Varnish (120 secondes par défaut). Un échec rend le déploiement rouge. Aucun endpoint de purge public, aucune nouvelle clé.
- Lot SFTP limité à 16 fichiers explicitement autorisés. Les documents internes, scripts, tests et configuration privée ne peuvent pas être ajoutés par une simple extension de fichier. Chemin distant fixé à htdocs ; aucun effacement distant.
- robots.txt, sitemap de sept pages, URL canoniques et Open Graph textuel. Aucune image de partage inventée.
- En-têtes nosniff, anti-iframe, referrer policy, permissions policy et CSP compatible avec les domaines Turnstile. Pas de HSTS global tant que le cas www reste ouvert.
- Formulaire : lecture bornée à 16 001 octets, rejet des origines tierces et contenus non JSON, délais clients explicites. Conservation de la vérification serveur Turnstile/hostname et de l’échappement HTML des courriels.
- Formulaire mobile : widget compact, y compris après redimensionnement, largeur minimale des grilles corrigée, champs à 16 px et explications à 14 px. Navigation clavier et réduction des animations déjà présentes.

## Vérifications et limites

Tests locaux : structure SEO, liens et ancres, sitemap, liste de publication, 49 tests existants de conservation. Tests PHP négatifs isolés exécutés dans GitHub Actions, PHP absent du Mac. Aucun message réel envoyé lors des tests automatisés.

Les coordonnées sociales sont cohérentes avec l’Annuaire des Entreprises et l’hébergeur avec la documentation Gandi. Les affirmations opérationnelles de la politique (classement et suppression des messages, paramètres du compte Turnstile, contrats sous-traitants) ne peuvent pas être certifiées par le seul audit du site. Les mécanismes de conservation existants n’ont pas été modifiés. Ceci est un contrôle de cohérence, pas une certification juridique ou RGAA.

La configuration privée Gandi n’a été ni lue ni modifiée. Aucun secret ajouté. DNS et redirection www inchangés. Après accord explicite, redirection HTTP vers HTTPS ajoutée uniquement sur le domaine principal, en tenant compte du proxy Gandi ; contrôle du chemin et des paramètres après déploiement. Pas de limitation IP ajoutée sans établir l’adresse client fiable derrière les proxys Gandi ; Turnstile reste la protection contre les envois automatisés. Les transferts SFTP ne forment pas une transaction globale ; un incident réseau peut nécessiter de relancer le déploiement.

## Suivi et retour arrière

Le workflow teste avant publication, conserve les déploiements en série et vérifie ensuite le contenu servi. En cas d’échec : examiner l’étape en erreur et le site avant toute nouvelle publication. Un revert Git du commit de correction sur main redéploie la version précédente ; conserver la configuration privée extérieure à htdocs. Les fichiers nouveaux non effacés par SFTP doivent être pris en compte lors d’un retour arrière.
